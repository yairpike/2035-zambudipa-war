## macOS

1. Double-click `ASEAN-2031-macOS.dmg`.
2. Drag `2035 - Zambudipa War` onto the `Applications` folder in the window that opens.
3. Open 2035 - Zambudipa War from Applications.

The first time, macOS blocks the game because it is not from the App Store. Right-click 2035 - Zambudipa War, choose Open, then Open again. On macOS 15 or later, go to System Settings, Privacy & Security, press Open Anyway, and confirm. You only do this once.

If you still have the old ASEAN 2031 app in Applications, you can move it to the Trash.

## Windows

1. Double-click `ASEAN-2031-Windows.exe`.
2. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.
3. Press Install. Leave "Play 2035 - Zambudipa War" ticked and press Finish.

The game is added to the Start menu and the desktop. An older ASEAN 2031 install and its shortcuts are replaced. Remove the game from Settings, Apps, like any other program.

## Linux

## LAN

Both players use the desktop game on the same network. Open Multiplayer. One player presses Host LAN. The other types the host address and presses Join LAN, or picks the host when it appears. Each player picks a faction, then presses Ready.

The match uses port 7777. The discovery beacon uses port 7778. Allow both through the firewall.
