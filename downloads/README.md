## iPhone and iPad (sideload)

Apple only allows apps outside the App Store through a sideloading tool, which signs the game with your own Apple ID. This build is new and has not yet been tried on an iPhone or iPad, so please report it if it closes right after opening.

**AltStore or SideStore:** download `ASEAN-2031-iOS.ipa` on the device, open AltStore or SideStore, go to My Apps, press +, and pick the file.

**Sideloadly (from a Mac or Windows PC):** connect the device with a cable, drag `ASEAN-2031-iOS.ipa` into Sideloadly, enter your Apple ID, and press Start.

Then:

1. On iOS 16 or later, turn on Settings, Privacy & Security, Developer Mode, and restart when asked.
2. If iOS says "Untrusted Developer", go to Settings, General, VPN & Device Management, choose your Apple ID, and press Trust.
3. Open 2035 - Zambudipa War from the home screen.

With a free Apple ID the app stops opening after 7 days; refresh it in AltStore or SideStore, or install it again with Sideloadly.

## LAN

Both players use the installed game (computer, Android, or iPhone/iPad) on the same network. Open Multiplayer. One player presses Host LAN. The other types the host address and presses Join LAN, or picks the host when it appears. Each player picks a faction, then presses Ready. On iPhone and iPad, allow Local Network access when asked, and type the host address if the host does not appear.

The match uses port 7777. The discovery beacon uses port 7778. Allow both through the firewall.
