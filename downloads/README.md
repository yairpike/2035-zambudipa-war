The first time the game opens, it downloads its music, voices, 3D models, and menu art (234 MiB) with a progress bar, then restarts by itself. This happens only once. Press Play now to start right away with simple models and no sound while the download finishes in the background.

## macOS

1. Double-click `ASEAN-2031-macOS.dmg`.
2. Drag `ASEAN 2031` onto the `Applications` folder in the window that opens.
3. Open ASEAN 2031 from Applications.

The first time, macOS blocks the game because it is not from the App Store. Right-click ASEAN 2031, choose Open, then Open again. On macOS 15 or later, go to System Settings, Privacy & Security, press Open Anyway, and confirm. You only do this once.

## Windows

1. Double-click `ASEAN-2031-Windows.exe`.
2. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.
3. Press Install. Leave "Play ASEAN 2031" ticked and press Finish.

The game is added to the Start menu and the desktop. Remove it from Settings, Apps, like any other program.

## Linux

1. Right-click `ASEAN-2031-Linux-x86_64.AppImage`, open Properties, and turn on "Allow executing file as program".
2. Double-click it.

## LAN

Both players use the desktop game on the same network. Open Multiplayer. One player presses Host LAN. The other types the host address and presses Join LAN, or picks the host when it appears. Each player picks a faction, then presses Ready.

The match uses port 7777. The discovery beacon uses port 7778. Allow both through the firewall.
